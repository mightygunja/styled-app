# Review Keywords → ASO Improvements

**This is how you let users do your marketing for you.**

---

## Common Review Phrases → ASO Actions

| Review Keyword / Phrase | Meaning | ASO Adjustment |
|------------------------|---------|----------------|
| **"Forgot to cancel"** | Surprise anxiety | Emphasize trial transparency in description |
| **"Didn't use it enough"** | Habit gap | Add "at your own pace" language |
| **"Too expensive"** | Value unclear | Emphasize fewer purchases benefit |
| **"Didn't fit my style"** | Personalization trust | Surface Style DNA earlier |
| **"Helpful but…"** | Almost there | Highlight explanations ("why it works") |
| **"Love the outfits"** | Core win | Use in screenshots captions |
| **"Simple / calm"** | Brand signal | Lean into minimal language |

## Detailed ASO Adjustments

### 1. "Forgot to cancel" → Trial Transparency

**Problem:** Users feel surprised by charges

**ASO Fix:**

**Add to description:**
```
Free 7-day trial with clear reminders before billing.
Subscriptions managed through your App Store account.
```

**Screenshot caption:**
```
"Clear trial status — no surprises"
```

**Keywords to add:**
- "transparent trial"
- "clear billing"
- "no surprise charges"

## Implementation Strategy

**Update App Store description:**
- Add trial transparency language

- Highlight "fewer purchases" benefit

**Update screenshot captions:**
- Use positive review phrases
- Emphasize clarity and calm
- Show Style DNA personalization

**Monitor reviews for new patterns:**

- Test different value propositions
- Measure conversion impact
- Iterate based on data

### Phase 3: Advanced (Quarterly)

**Create seasonal variations:**
- Adjust keywords for trends

- Refresh social proof

## Review Monitoring System

### Track These Metrics

**Positive signals:**
- "Love the outfits" frequency
- "Simple / calm" mentions
- "Helpful" + specific feature
- "Personalized" references

**Warning signals:**
- "Forgot to cancel" frequency
- "Too expensive" mentions
- "Didn't fit my style" complaints
- "Didn't use it enough" patterns

### Response Triggers

**If "Forgot to cancel" > 10% of reviews:**
- Increase trial transparency in description
- Add reminder clarity to screenshots
- Update paywall copy

**If "Didn't use it enough" > 15% of reviews:**
- Emphasize "at your own pace" more
- Reduce pressure language
- Highlight flexible usage

**If "Too expensive" > 20% of reviews:**
- Clarify value proposition
- Emphasize savings benefit
- Test pricing variations

## Screenshot Caption Principles (High Impact)

### ✅ Do:
- Use emotional language: "feel like you"
- Be direct and confident: "Clear reasons. No guesswork."
- Focus on user benefit, not features
- Keep it conversational

### ❌ Don't:
- Use technical jargon: "personalized outfits"
- Be vague: "smart recommendations"
- Lead with features: "AI-powered"
- Sound corporate

### Keyword Placement

**App Name:** Styled

**Subtitle:** Get dressed with confidence using what you already own

**Keywords field (Hidden Metadata):**
```
personal style, outfit planning, wardrobe helper, closet app, daily outfit, minimal fashion, style advice, wardrobe organizer, outfit ideas, closet manager, get dressed, style DNA, calm styling, use what you own, no trends
```

**Focus on intent, not fashion buzzwords**

**✅ Include:**
- personal style
- outfit planning
- wardrobe helper
- closet app
- daily outfit
- minimal fashion

**❌ Avoid:**
- "trendy" - Attracts wrong expectations
- "AI stylist" - Too technical, wrong audience
- "shopping app" - Not our value proposition

**Why:** These keywords attract users looking for help getting dressed, not shopping or following trends.

## Monthly Review Audit

### Process

1. **Export all reviews from last 30 days**
2. **Categorize by keyword themes**
3. **Calculate frequency percentages**
4. **Identify top 3 patterns**
5. **Update ASO accordingly**

### Template

```
Month: [Month Year]

Positive Keywords:
- "Love the outfits": 45% (↑ from 40%)
- "Simple / calm": 32% (↑ from 28%)
- "Helpful explanations": 28% (↑ from 25%)

Warning Keywords:
- "Forgot to cancel": 8% (↓ from 12%)
- "Too expensive": 15% (→ same)
- "Didn't use enough": 12% (↓ from 15%)

ASO Actions:
1. Maintain trial transparency (working)
2. Test value proposition variations (expensive mentions stable)
3. Continue "at your own pace" messaging (usage improving)
```
