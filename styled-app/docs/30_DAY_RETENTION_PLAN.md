# First 30 Days Retention Plan - Behavioral Design

**This is how you win: Behavioral design, not notification spam.**

The goal is to build a habit loop where users naturally return to Styled because it makes their life easier, not because we nag them.

---

## Core Principle

**Make Styled part of their morning routine, not an interruption.**

Users should think: "What should I wear today?" → Open Styled → Get answer → Feel confident

---

## The Habit Loop

```
Trigger → Action → Reward → Investment
```

1. **Trigger:** Morning decision fatigue ("What do I wear?")
2. **Action:** Open Styled, see outfit suggestion
3. **Reward:** Confidence, time saved, compliment received
4. **Investment:** Add item, save outfit, build StyleDNA

Each investment makes the next visit more valuable.

---

## 30-Day Journey

### Week 1: Foundation (Days 1-7)
**Goal: Complete StyleDNA, add 5+ items, generate first outfit**

#### Day 1: Onboarding
- ✅ Complete StyleDNA onboarding (7 steps)
- ✅ Add first 3-5 closet items
- ✅ Generate first outfit
- **Reward:** "Your style profile is ready!"
- **No notifications yet** - Let them explore

#### Day 2-3: First Success
- **Trigger:** Morning (9-10am) - "Good morning! Ready to get dressed?"
- **Action:** Open app, see outfit suggestion
- **Reward:** Quick decision, confidence boost
- **Investment:** Mark outfit as worn, add feedback

#### Day 4-5: Building Habit
- **Trigger:** Morning routine established
- **Action:** Check outfit before getting dressed
- **Reward:** Consistent good choices
- **Investment:** Add more closet items naturally

#### Day 6-7: First Milestone
- **Achievement unlocked:** "7 days of great outfits!"
- **Reward:** Show stats (outfits created, time saved)
- **No push notification** - Show in-app when they open

---

### Week 2: Habit Formation (Days 8-14)
**Goal: Daily usage becomes automatic**

#### Day 8-10: Expand Wardrobe
- **Smart Gap suggestion:** "One versatile layer would unlock more outfits — no rush."
- **Trigger:** After generating 3rd outfit of the week
- **Action:** User adds suggested item type
- **Reward:** See immediate impact (more outfit options)

#### Day 11-14: Social Proof
- **In-app message:** "You've created 10 outfits this week!"
- **Reward:** Visual progress (outfit history)
- **Investment:** Save favorite outfits for quick access

---

### Week 3: Value Deepening (Days 15-21)
**Goal: User sees Styled as essential, not optional**

#### Day 15: Paywall Trigger (Free Users)
- **After 3 outfits:** Soft paywall appears
- **Message:** "You're getting the hang of this!"
- **Offer:** 7-day free trial
- **No pressure** - "Maybe later" option available

#### Day 16-18: Plus Features (Paid Users)
- **Unlock:** Advanced analytics
- **Show:** "Your most-worn colors this week"
- **Reward:** Insights about their style
- **Investment:** Deeper StyleDNA engagement

#### Day 19-21: Routine Solidified
- **Morning check-in becomes automatic**
- **No notifications needed** - Habit is formed
- **Reward:** Consistent confidence

---

### Week 4: Retention Lock-In (Days 22-30)
**Goal: User can't imagine life without Styled**

#### Day 22-25: Showcase Value
- **In-app summary:** "This month, Styled saved you 2 hours of decision time"
- **Show:** Outfit history, favorite combinations
- **Reward:** Tangible proof of value

#### Day 26-28: Expand Use Cases
- **Suggest:** "Plan outfits for the week ahead"
- **Action:** User creates outfits for upcoming events
- **Investment:** Calendar integration, outfit planning

#### Day 29-30: Milestone Celebration
- **Achievement:** "30 days of confident style!"
- **Reward:** Personalized insights
- **Next:** "Keep your streak going"

## Notification Strategy (Minimal)

### Week 1: ZERO push notifications
- Let users discover the app naturally
- Build trust before asking for attention

### Week 2: ONE optional morning reminder
- "Good morning! Your outfit is ready" (9am)
- **Only if:** User opened app 3+ times in Week 1
- **Easy opt-out:** "No thanks, I'll check when ready"

### Week 3: Smart triggers only
- Outfit planning reminder (evening before event)
- **Only if:** User added calendar event
- **Never generic** - Always contextual

### Week 4: Celebration, not nagging
- Milestone achievements (in-app only)
- **Never:** "You haven't opened the app"
- **Always:** "You're doing great!"

---

## Behavioral Triggers (Not Notifications)

### 1. Morning Routine Integration
- **When:** User typically gets dressed (learned from usage)
- **What:** App icon badge with outfit count
- **Not:** Push notification

### 2. Event-Based
- **When:** Calendar shows event tomorrow
- **What:** In-app prompt to plan outfit
- **Not:** Intrusive notification

### 3. Weather-Based
- **When:** Weather changes significantly
- **What:** Suggest seasonal outfit when app opens
- **Not:** Weather alert spam

### 4. Success Reinforcement
- **When:** User marks outfit as worn
- **What:** Quick "Looking good!" confirmation
- **Not:** Excessive praise

## What NOT to Do

### ❌ Never:
- Send generic "We miss you" notifications
- Spam with daily reminders
- Pressure users to upgrade
- Show ads or shopping links
- Interrupt their flow with popups
- Send notifications after 9pm

### ✅ Always:
- Respect user's time
- Provide value before asking for anything
- Make features discoverable, not intrusive
- Celebrate progress, not shame absence
- Let users control notification preferences
- Build trust through consistency

## Success Indicators

### User is retained if:
1. **Opens app 3+ times per week** (habit formed)
2. **Generates outfits regularly** (finds value)
3. **Adds items over time** (investment increases)
4. **Marks outfits as worn** (real-world usage)
5. **Subscribes to Plus** (sees enough value to pay)

### User is at risk if:
1. Opens app <2 times in Week 2
2. Hasn't added items since Day 1
3. Generates outfits but never marks as worn
4. Dismisses all Smart Gap suggestions
5. Doesn't complete StyleDNA

---

## Recovery Strategies (For At-Risk Users)

### Low Engagement (Week 2)
- **In-app message:** "Need help getting started?"
- **Offer:** Quick tutorial or style quiz
- **Not:** "You haven't used the app"

### Sparse Closet (Week 3)
- **Show:** "You're off to a great start" message
- **Encourage:** Add 1-2 more pieces
- **Not:** "Your closet is too small"

### Paywall Bounce (Week 3)
- **Remind:** Value received so far
- **Offer:** Extended trial or special pricing
- **Not:** Aggressive upsell

## The Retention Formula

```
Retention = (Value Delivered) × (Habit Strength) × (Investment Made)
```

**Value Delivered:**
- Time saved on outfit decisions
- Confidence boost from good choices
- Compliments received

**Habit Strength:**
- Morning routine integration
- Consistent usage pattern
- Automatic behavior

**Investment Made:**
- Items added to closet
- StyleDNA completed
- Outfits saved/planned
- Subscription purchased

## Remember

**Users stay because Styled makes their life better, not because we remind them to.**

Build the habit loop. Deliver value. Respect their time.

**That's how you win.**
